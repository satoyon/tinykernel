Detailed Description

計数セマフォ (Counting Semaphore) / バイナリセマフォ

資源の獲得・返却によるタスク間同期を行います。資源がない場合はタスクが State::Blocked に遷移して休止し、返却時に優先度の高いタスクから順に起床します。

tk::Semaphore sem(0, 5); // 初期値0、最大5
// タスク側 (資源が空くまでブロック待機)
sem.acquire();
// シグナル送信側 (割り込みや他タスクから返却・通知)
sem.release();
