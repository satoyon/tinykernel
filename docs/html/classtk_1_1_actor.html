template<typename MsgType = Message, size_t QueueSize = 8>
class tk::Actor< MsgType, QueueSize >

メッセージ駆動型タスク (アクター) の基底クラス

固定長リングバッファ付きのメッセージキューを持ち、メッセージ到着時に自動起床して on_message() を実行します。メッセージが無い時は CPU を消費せずブロック待機します。

テンプレート引数
MsgType受信するメッセージの型 (デフォルト: tk::Message)
QueueSizeメッセージキューの最大保持件数 (デフォルト: 8)
struct SensorMsg { float temp; };
class SensorActor : public tk::Actor<SensorMsg, 8> {
protected:
void on_start() override {
// デバイスの初期化
}
void on_message(const SensorMsg& msg) override {
printf("Temp: %.1f\n", msg.temp);
}
};
