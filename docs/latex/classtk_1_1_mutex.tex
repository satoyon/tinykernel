\doxysubsection{Detailed Description}
所有権・優先度順ウェイクアップ・\+RAII 対応のミューテックス (排他ロック) 

共有リソースやペリフェラルへの同時アクセスを防止します。 ロックしたタスク本人以外の誤った {\ttfamily \doxylink{classtk_1_1_mutex_ae8d5dfd5655b5aa54d63db6e0cf2f707}{unlock()}} は安全に無視されます。 C++ の {\ttfamily Basic\+Lockable} を満たしており、{\ttfamily std::\+lock\+\_\+guard} や {\ttfamily \doxylink{classtk_1_1_lock_guard}{tk::\+\+Lock\+Guard}} が利用可能です。
